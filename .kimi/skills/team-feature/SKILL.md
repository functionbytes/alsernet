# /team-feature — Parallel Feature Implementation

Launch agent team for parallel backend+frontend+testing implementation.

## When to use
- Medium-to-large features spanning multiple layers
- Need parallel work on backend, frontend, and tests

## Team composition
- **backend**: Implements controllers, services, models
- **frontend**: Implements Blade views, JS, CSS
- **testing**: Writes and runs tests concurrently
