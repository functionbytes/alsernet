# /module-audit — Full Module Audit

Comprehensive audit covering security, performance, code quality, and test coverage.

## When to use
- Pre-release review
- Code quality assessment
- Security review of a module

## Audit areas
- **Security**: Auth, XSS, SQL injection, mass assignment, permissions
- **Performance**: N+1 queries, missing indexes, caching
- **Quality**: Code style, complexity, duplication
- **Tests**: Coverage, assertions, edge cases
