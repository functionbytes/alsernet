Bienvenido a Tienda Demo

Esta es una página de prueba para verificar la integración del widget de chat con el panel del agente.

Al navegar entre las páginas del menú, el widget enviará page views al backend. Cuando inicies un chat, el agente verá toda esta información en la pestaña "Tecnología".

📞 Pasos para probar

  1. Navega entre las páginas del menú superior (Inicio → Productos → Ofertas → Contacto → Sobre nosotros)
  2. Cada navegación registra una page view en el backend
  3. Espera ~3 segundos a que aparezca la burbuja del widget (esquina inferior derecha)
  4. Haz clic para abrir el widget
  5. Si aparece pre-chat form, llena nombre y email
  6. Escribe un mensaje y envíalo
  7. Abre https://system.test/panel/helpdesk/conversations y selecciona la conversación
  8. En el panel derecho verás la pestaña "Tecnología" con IP, navegador, OS, dispositivo, país, tiempo en sitio y la lista de páginas que visitaste

🔧 Configuración técnica

Token: HelpdeskDemoToken_st6u4YVxLS
