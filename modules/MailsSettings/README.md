# MailsSettings Module

Email Configuration Settings Module for Alsernet Manager.

## Description

This module provides configuration interfaces for:
- Outgoing email (SMTP)
- Incoming email (IMAP)
- Email actions by stage
- General email settings

## Features

- SMTP configuration interface
- IMAP configuration interface
- Stage-based email actions
- Email settings management

## Dependencies

- Settings model (App\Models\Setting)
- Laravel Mail configuration

## Routes

All routes are prefixed with `manager/settings/email`

## Views

Views are namespaced under `mails-settings::`
